## 🚀 Featured Data Projects

### 🪖 [US Army Soldier Ethnicity Prediction (ANSUR II)](https://github.com/sevvalnrdede/US-Army-Ethnicity-Prediction-ANSUR-II)
* **Domain:** Supervised Classification & Imbalanced Data Handling
* **Core Stack:** Python, Scikit-Learn, XGBoost, SMOTE
* **Summary:** Built an end-to-end classification ecosystem to predict military personnel ethnicity from multi-dimensional anthropometric body measurements. Successfully resolved extreme class imbalance via custom loss weights and resampling, achieving **89% validation accuracy** with XGBoost.

### 🚗 [Auto Scout Car Price Prediction](https://github.com/sevvalnrdede/Auto-Scout-Car-Price-Prediction)
* **Domain:** Predictive Modeling & Regression Analysis
* **Core Stack:** Python, Pandas, Scikit-Learn Regression Suite
* **Summary:** Formulated a complete regression pipeline to clean heavily nested automotive market data, engineer domain-specific pricing features, and optimize tree-based models to forecast used vehicle values with exceptional residual accuracy.

### 🛍️ [Customer Segmentation Hub](https://github.com/sevvalnrdede/Customer-Segmentation-Unsupervised-Learning)
* **Domain:** Unsupervised Clustering & Behavioral Analytics
* **Core Stack:** Python, KMeans, Agglomerative Clustering, SciPy
* **Summary:** Mapped retail shopping personas using spatial transaction markers. Rigorously verified clustering tendencies via the **Hopkins Statistic** and determined optimal consumer group boundaries using **Silhouette Score optimization (0.554)** and hierarchical dendrograms.

### 🖋️ [Handwritten Digits Classifier](https://github.com/sevvalnrdede/Handwritten-Digits-Classification-SVM-DT-RF)
* **Domain:** Pattern Recognition & Multi-Class Comparison
* **Core Stack:** Python, Support Vector Machines (SVM), Random Forest
* **Summary:** Implemented a benchmarking framework evaluating digit pen trace path coordinates. Reached **99.45% accuracy** using a non-linear RBF-kernel SVM, highlighting operational performance limits against traditional decision trees.
